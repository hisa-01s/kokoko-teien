牡蠣のリゾットの作り方｜生米から作る本格レシピと、ごはんで作る簡単レシピ、ぷっくり仕上げるコツ

更新日：2026.11.04

「旬の牡蠣を使って、少し特別な料理を作りたい」「レストランのような牡蠣のリゾットを家で味わいたい」。そんな方におすすめなのが牡蠣のリゾットです。牡蠣のうまみがお米にしみ込んだリゾットは、寒い季節にぴったりのごちそうです。この記事では、牡蠣の下ごしらえと、生米から作る本格レシピ、ごはんで作る簡単レシピ、牡蠣をぷっくり仕上げるコツを紹介します。

牡蠣の選び方と下ごしらえ

おいしいリゾットを作るために、まずは牡蠣の選び方と下ごしらえを確認しておきましょう。

リゾットには「加熱用」の牡蠣を

牡蠣には「生食用」と「加熱用」があります。これは鮮度の違いではなく、とれた海域などによる区分です。加熱用の牡蠣は身が大きく、うまみが濃いものが多いため、リゾットなどの加熱料理に向いています。旬は冬（11〜3月ごろ）です。

臭みを抑える洗い方

  1. ボウルに牡蠣を入れ、片栗粉大さじ1と塩少々をまぶす
  2. やさしくもみ洗いし、汚れを片栗粉に吸着させる
  3. 灰色になった片栗粉を、流水でていねいに洗い流す
  4. キッチンペーパーで水気をしっかりふき取る

片栗粉で洗うと、ひだの間の汚れが落ち、臭みが抑えられます。

中心まで十分に加熱する

牡蠣を加熱して食べる場合は、中心部まで十分に火を通すことが大切です。目安として、中心部が85〜90℃で90秒以上加熱することがすすめられています。リゾットに加えたあとも、しっかり火を通しましょう。

生米から作る本格的な牡蠣のリゾット

お米のアルデンテの食感が楽しめる、本格的なリゾットの作り方です。

材料（2人分）

  • 加熱用牡蠣：150〜200g
  • 米：1合（洗わずに使う）
  • 玉ねぎ：1/4個
  • にんにく：1片
  • オリーブオイル：大さじ1
  • 白ワイン：50ml
  • 水：600〜700ml
  • 顆粒コンソメ：小さじ2
  • バター：10g
  • 粉チーズ：大さじ2
  • 塩・こしょう・パセリ：適量

作り方

  1. 水とコンソメを小鍋で温め、スープを用意しておく
  2. フライパンにオリーブオイルとにんにくを入れて弱火で熱し、牡蠣を両面焼く
  3. 牡蠣がぷっくりしたら白ワイン半量を加えてさっと煮て、牡蠣を取り出す（煮汁は残す）
  4. 同じフライパンで玉ねぎのみじん切りを炒め、米を加えて透き通るまで炒める
  5. 残りの白ワインを加え、温かいスープをお玉1杯ずつ加えながら、混ぜすぎないように煮る
  6. 15〜18分ほどで米に少し芯が残る状態になったら、牡蠣を戻し入れて温め、中まで火を通す
  7. 火を止めてバターと粉チーズを加え、塩・こしょうで味をととのえ、パセリをちらす

ごはんで作る簡単な牡蠣のリゾット

残りごはんを使えば、短時間で手軽にリゾットが作れます。

簡単レシピの作り方（2人分）

  1. ごはん300gはざるに入れてさっと洗い、ぬめりを取る
  2. フライパンにバターを溶かし、下ごしらえした牡蠣を焼いて取り出す
  3. 同じフライパンで玉ねぎを炒め、水300ml、コンソメ小さじ2、牛乳100mlを加える
  4. 煮立ったらごはんを加え、とろみがつくまで5分ほど煮る
  5. 牡蠣を戻し入れて中まで火を通し、粉チーズと塩・こしょうで味をととのえる

ごはんをさっと洗うことで、粘りが出すぎず、さらっとしたリゾットに仕上がります。

牡蠣をぷっくり仕上げるコツとアレンジ

牡蠣のリゾットをよりおいしく作るためのポイントを紹介します。

牡蠣は一度取り出して最後に戻す

牡蠣をお米と一緒に長時間煮込むと、身が縮んでかたくなってしまいます。最初に焼いて取り出し、仕上げに戻し入れて中まで温めると、ぷっくりとした食感を保てます。牡蠣を焼いたときに出た煮汁は、うまみたっぷりなので、リゾットに必ず加えましょう。

味のアレンジ

アレンジ作り方のポイント
クリームリゾット仕上げに生クリームを加えて、濃厚でまろやかな味に
トマトリゾットスープの一部をトマト缶にかえて、さっぱりとした味に
和風リゾットコンソメの代わりにだしを使い、しょうゆと三つ葉で香りよく
ほうれん草入りゆでたほうれん草を加えて、彩りと栄養をプラス

料理を趣味として楽しみたい方は、牛肉の赤ワイン煮込みなど、ほかのおもてなし料理にも挑戦してみてください。

まとめ

牡蠣のリゾットは、加熱用の牡蠣を片栗粉で洗って臭みを抑え、最初に焼いて取り出し、仕上げに戻して中まで火を通すのがおいしく作るコツです。生米から作れば本格的なアルデンテの食感に、ごはんを使えば短時間で手軽に作れます。

牡蠣を焼いたときの煮汁もリゾットに加えて、うまみを余さず味わいましょう。クリームやトマト、和風など、アレンジも楽しみながら、旬の牡蠣を使ったごちそうを作ってみてください。
