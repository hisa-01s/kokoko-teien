目の疲れを取る方法｜簡単にできる即効ケアと疲れ目の予防法

更新日：2026.11.07

「夕方になると目がしょぼしょぼする」「画面を見ていると目の奥が重くなる」。スマホやパソコンが欠かせない今、目の疲れに悩む人はとても増えています。目の疲れを放っておくと、頭痛や肩こりなど全身の不調につながることもあります。この記事では、目の疲れが起こる原因と眼精疲労との違いを整理したうえで、ホットタオルやツボ押し、目のストレッチなど簡単にできる目の疲れを取る方法、疲れ目を溜めないための作業環境や食事、眼科を受診する目安までをわかりやすく解説します。今日からすぐに試せるケアばかりなので、ぜひ取り入れてみてください。

目の疲れが起こる原因

目の疲れは、今や多くの人が抱える身近な悩みです。仕事ではパソコン、移動中や寝る前にはスマホと、1日の大半を画面とともに過ごしている人も多いでしょう。「目が疲れるのは当たり前」と感じていても、なぜ疲れるのかを知っている人は意外と少ないかもしれません。

目の疲れの主な原因は、画面を見続けることによる目の筋肉の緊張と、まばたきが減ることによる目の乾燥です。近くの一点を長時間見つめていると、ピントを合わせる筋肉が休む暇なく働き続けます。さらに、集中しているとまばたきの回数が減り、目の表面が乾きやすくなります。

こうした負担が積み重なると、休んでもなかなか回復しない「眼精疲労」に進むこともあります。原因を正しく知ることで、どのような対策が効果的なのかが見えてきます。

この章では、スマホやパソコンが目に与える影響、ピント調節筋の緊張とドライアイ、そして目の疲れと眼精疲労の違いについて解説します。

スマホ・パソコンの長時間使用による目の疲れ

目の疲れの大きな原因の一つが、スマホやパソコンの長時間使用です。画面を見ているとき、目には次のような負担がかかっています。

  • 近くの画面に長時間ピントを合わせ続ける
  • 画面に集中してまばたきが減り、目が乾きやすくなる
  • 画面の明るさと周囲の明るさの差に目が対応し続ける
  • 細かい文字を読み取ろうと目を凝らす

厚生労働省のガイドラインでは、パソコンなどの作業について、1時間を超えないようにし、作業の合間に10〜15分程度の休止時間を設けることが目安とされています。しかし実際には、仕事で何時間も続けて画面を見たあと、休憩中や帰宅後もスマホを見ているという人も多いのではないでしょうか。

よくある使い方の問題点として、次のようなものが挙げられます。

  • 暗い部屋でスマホを見る
  • 寝転がって顔の近くで画面を見る
  • 休憩時間もスマホを見て目を休めていない
  • 画面の明るさを最大にしたまま使っている

こうした習慣が重なると、目の疲れはどんどん蓄積していきます。

ピント調節筋の緊張とドライアイ

目の疲れには、ピントを合わせる筋肉の緊張と、目の乾燥の2つが大きく関わっています。

目の中には、レンズの役割をする水晶体と、その厚みを調節する「毛様体筋（もうようたいきん）」という筋肉があります。近くを見るとき、毛様体筋は縮んで水晶体を厚くし、ピントを合わせます。反対に遠くを見るときは、毛様体筋がゆるみます。

つまり、スマホやパソコンなど近くを見続けているあいだ、毛様体筋はずっと縮みっぱなしの状態です。腕を曲げたまま重い荷物を持ち続けると疲れるのと同じように、毛様体筋も緊張が続くと疲れてしまい、ピントが合いにくくなったり、目が重く感じたりします。

もう一つの原因が「ドライアイ」です。ドライアイとは、涙の量が減ったり、涙の質が低下したりして、目の表面が乾いてしまう状態のことです。人は通常1分間に15〜20回ほどまばたきをしますが、画面に集中すると、その回数が大きく減るといわれています。まばたきが減ると涙が目の表面に行き渡らず、乾燥やゴロゴロ感、充血などが起こりやすくなります。

目の疲れと眼精疲労の違い

「目の疲れ」と「眼精疲労」は似た言葉ですが、意味は異なります。違いを表で比較してみましょう。

項目目の疲れ（疲れ目）眼精疲労
状態目を使ったことによる一時的な疲れ目の疲れが慢性化した状態
回復休息や睡眠で回復する休んでも十分に回復しない
主な症状目のかすみ、しょぼしょぼ感、重さ目の痛み、かすみ、充血に加え全身症状
全身への影響ほとんどない頭痛、肩こり、吐き気、イライラなど

一時的な目の疲れであれば、目を休めたり、一晩ぐっすり眠ったりすることで回復します。しかし、目を酷使する生活が続くと、疲れが取れないまま積み重なり、眼精疲労へと進んでしまうことがあります。

眼精疲労になると、目だけでなく、頭痛や肩こり、首のこり、吐き気、集中力の低下、イライラといった全身の症状が表れることもあります。「目の疲れくらい」と軽く考えず、早めにケアすることが大切です。

眼精疲労のセルフチェック

自分の目の疲れが眼精疲労に進んでいないか、次の項目でチェックしてみましょう。

  • 一晩寝ても目の疲れが取れない
  • 目の奥に痛みや重さを感じる
  • 目がかすんだり、ぼやけたりすることが多い
  • 目が充血しやすい
  • まぶしさを強く感じる
  • 目が乾いてゴロゴロする
  • 頭痛や肩こりが続いている
  • 目を使ったあとに吐き気を感じることがある
  • 集中力が続かず、イライラしやすい
  • 1日に合計6時間以上画面を見ている

当てはまる項目が多いほど、眼精疲労の可能性が高くなります。特に、休んでも回復しない、目の痛みや頭痛が続くといった項目に当てはまる場合は注意が必要です。

当てはまる数が多い場合や、症状がつらい場合は、セルフケアだけで済ませず、眼科の受診を検討しましょう。目の疲れの背景に、視力の変化やメガネ・コンタクトの度数の不一致、目の病気などが隠れていることもあります。

簡単にできる目の疲れを取る方法

ここからは、自宅や職場で簡単にできる目の疲れを取る方法を紹介します。特別な道具がなくても、ちょっとした工夫で目をいたわることができます。

目の疲れを取る方法の基本は、「温める」「ほぐす」「休ませる」の3つです。目を温めると血行がよくなり、緊張した筋肉がゆるみやすくなります。目の周りのツボ押しやマッサージは、こわばった目元をほぐすのに役立ちます。そして、遠くを見たり目のストレッチをしたりすることで、近くを見続けて疲れた目の筋肉を休ませることができます。

どの方法も数分でできるものばかりです。仕事の合間や寝る前など、生活の中に取り入れやすいタイミングで実践してみてください。

この章では、ホットタオルや蒸気で目を温める方法、目の周りのツボ押しとマッサージ、目のストレッチと遠くを見る休憩法、そして仕事中でも取り入れやすい「20-20-20ルール」を紹介します。

目を温める（ホットタオル・蒸気）方法

目の疲れを取る方法として手軽で効果的なのが、目を温めることです。目の周りを温めると血行がよくなり、緊張していた目の筋肉がゆるみやすくなります。また、まぶたにある油を出す腺の働きが促され、涙の蒸発を防ぐ油分が分泌されやすくなるため、目の乾燥対策にもつながります。

ホットタオルの作り方と使い方は次のとおりです。

  1. フェイスタオルを水でぬらし、軽く絞る
  2. タオルを折りたたみ、電子レンジ（500〜600W）で30秒〜1分ほど温める
  3. 手首の内側に当てて、熱すぎないか確認する
  4. 目を閉じて、まぶたの上にタオルをのせる
  5. 5分ほど、タオルが冷めるまで温める

電子レンジから取り出した直後は熱くなっていることがあるため、やけどには十分注意してください。少し広げて冷ましてから使うと安心です。

電子レンジがない職場では、市販の蒸気で温めるアイマスクを使うのも便利です。入浴中に、湯船につかりながら温かいタオルを目にのせるのもおすすめです。ただし、目が充血していたり、かゆみや炎症があったりする場合は、温めると悪化することもあるため控えましょう。

目の周りのツボ押し・マッサージ

目の周りには、目の疲れに効くといわれるツボがいくつかあります。代表的なツボと位置の目安は次のとおりです。

ツボ位置の目安
晴明（せいめい）目頭と鼻の付け根のあいだのくぼみ
攅竹（さんちく）眉頭の内側のくぼみ
太陽（たいよう）こめかみの、眉尻と目尻の中間から少し外側のくぼみ
四白（しはく）黒目の真下、目の下の骨から指1本分下

押し方は、指の腹をツボに当て、息を吐きながら3〜5秒かけてゆっくり押し、力をゆるめます。これを1カ所につき3〜5回ほどくり返しましょう。

ツボ押しのあとは、目の周りをやさしくマッサージするのもおすすめです。目を閉じ、人差し指から薬指の3本の指の腹で、眉の下と目の下の骨のふちを、目頭から目尻に向かって軽くなでるようにさすります。

注意点として、眼球を直接押すのは絶対に避けてください。目の周りの皮膚は薄くデリケートなため、強くこすりすぎないことも大切です。コンタクトレンズを外し、手を清潔にしてから行いましょう。

目のストレッチ・遠くを見る休憩法

近くを見続けて疲れた目には、目のストレッチや遠くを見る休憩が効果的です。毛様体筋の緊張がゆるみ、目の疲れを和らげる助けになります。

目のストレッチの手順

  1. 顔は正面に向けたまま、目だけを上・下・左・右の順にゆっくり動かす
  2. それぞれの方向で2〜3秒ずつ止める
  3. 目をゆっくり右回り、左回りに大きく1周ずつ回す
  4. 最後にぎゅっと目を閉じて3秒キープし、ぱっと大きく開く

遠近ストレッチの手順

  1. 人差し指を立て、目の前30cmほどの位置に置く
  2. 指先に3秒ほどピントを合わせる
  3. 次に、窓の外など遠くの景色に3秒ほどピントを合わせる
  4. これを5〜10回くり返す

仕事の合間に取り入れやすいタイミングとしては、次のようなときがおすすめです。

  • 1つの作業が終わったとき
  • メールを送信したあと
  • 会議の始まる前
  • トイレ休憩や飲み物を取りに行くとき

意識的に目を休める時間を作ることで、目の疲れを溜めにくくなります。

20-20-20ルールで目を休める

目の疲れを防ぐ休憩法として知られているのが「20-20-20ルール」です。アメリカの眼科医が提唱した方法で、覚えやすく、仕事中にも取り入れやすいのが特徴です。

ルールの内容は次のとおりです。

数字内容
20分ごとに画面を見る作業を20分続けたら
20フィート（約6m）先を窓の外や部屋の奥など、遠くにあるものを
20秒間見る20秒ほど眺めて目を休める

約6m以上離れたものを見ると、毛様体筋がゆるみ、ピント調節の緊張がほぐれやすくなります。わずか20秒でも、こまめに目を休めることが大切です。

習慣化のコツは次のとおりです。

  • スマホやパソコンのタイマーを20分ごとにセットする
  • 目を休めるアプリやブラウザの拡張機能を活用する
  • 遠くを見るときに、深呼吸や肩回しも一緒に行う
  • 窓の近くなど、遠くを見やすい場所に席を作る

最初は忘れてしまうこともありますが、タイマーなどを活用すれば自然と習慣になります。まずは午前中だけなど、無理のない範囲から始めてみましょう。

目の疲れを溜めない予防と受診の目安

目の疲れを取る方法を知っておくことは大切ですが、それ以上に大切なのが、そもそも目の疲れを溜めないようにすることです。目を使う時間を減らすのが難しくても、作業環境や生活習慣を少し見直すだけで、目への負担を減らすことができます。

予防の基本は、画面との距離や明るさを適切に保つこと、目によい栄養をとること、そして十分な休息をとることです。毎日長時間画面を見る人ほど、こうした予防策の積み重ねが目の健康を守ることにつながります。

一方で、セルフケアや予防を続けても目の疲れが取れない場合は、目の病気や視力の変化が隠れていることもあります。そのようなときは、自己判断せずに眼科を受診することが大切です。

この章では、作業環境の整え方、目の疲れによい食事と栄養素、そして眼科を受診する目安について解説します。

画面との距離・明るさなど作業環境の整え方

目の疲れを予防するには、パソコンやスマホを使う環境を整えることが大切です。次のポイントを確認してみましょう。

  • 画面との距離：パソコンは40cm以上、スマホは30cm以上離して見る
  • 画面の高さ：画面の上端が目の高さと同じか、やや下になるようにする
  • 画面の明るさ：周囲の明るさに合わせて調整し、まぶしすぎないようにする
  • 文字の大きさ：目を凝らさなくても読める大きさに設定する
  • 画面の角度：照明や窓の光が映り込まないように調整する
  • 姿勢：背もたれに背中をつけ、足裏を床につけて座る

画面の位置をやや下に置くと、目を大きく開かずに済むため、目の表面が乾きにくくなります。

部屋の照明にも気を配りましょう。暗い部屋で明るい画面を見ると、明るさの差が大きく目が疲れやすくなります。部屋全体を適度な明るさに保つことが大切です。

また、スマホやパソコンから出るブルーライトが気になる場合は、画面の夜間モードやブルーライトを抑える設定を使うのもよいでしょう。特に夜は、ブルーライトが睡眠に影響することもあるといわれているため、寝る前の画面の使用は控えめにするのがおすすめです。

目の疲れに良い食事・栄養素

毎日の食事で、目の健康によいとされる栄養素をとることも、目の疲れ対策の一つです。代表的な栄養素と多く含まれる食材を整理しました。

栄養素期待される働き多く含まれる食材
ビタミンA目の粘膜を健康に保つ、暗い場所での見え方を助けるレバー、うなぎ、にんじん、かぼちゃ
アントシアニン目の働きをサポートするとされるポリフェノールブルーベリー、カシス、なす
ルテイン光の刺激から目を守るとされる色素成分ほうれん草、ブロッコリー、ケール
ビタミンB群目の神経や筋肉の働きを支える豚肉、玄米、納豆、卵
DHA目の網膜に多く含まれる脂肪酸さば、いわし、さんま

これらの栄養素は、一度にたくさんとるよりも、毎日の食事でバランスよくとることが大切です。たとえば、緑黄色野菜を使ったおかずを1品増やす、魚を食べる日を週に数回作るといった工夫から始めてみましょう。

ただし、食事はあくまで目の健康を支える補助的なものです。特定の食材を食べたからといって、すぐに目の疲れが取れるわけではありません。目を休める習慣や十分な睡眠とセットで考えることが大切です。

目の疲れが取れないときに眼科を受診する目安

セルフケアや予防を続けても目の疲れが取れない場合や、次のような症状がある場合は、早めに眼科を受診しましょう。

  • 目の痛みが続いている
  • 視力が急に低下した、見え方がおかしい
  • 目のかすみやぼやけが続いている
  • 物が二重に見える
  • 視界の一部が欠けて見える、ゆがんで見える
  • 強い充血や目やにが続いている
  • 頭痛や吐き気をともなう目の疲れがある
  • メガネやコンタクトレンズが合っていない気がする

目の疲れの背景には、ドライアイや緑内障などの目の病気、老眼の始まり、メガネやコンタクトの度数が合っていないことなどが隠れている場合もあります。これらは自分では気づきにくいため、眼科で検査を受けることが大切です。

特に、視力の低下や視野の異常は、早めの対応が必要な病気のサインであることもあります。「そのうち治るだろう」と放置せず、気になる症状があれば早めに眼科医に相談しましょう。目は一生使う大切な器官です。日頃のケアと早めの受診で、目の健康を守っていきましょう。
