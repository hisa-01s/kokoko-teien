# 枯山水の作り方｜自宅の坪庭でできるDIY手順と道具、砂紋の描き方を初心者向けに解説

「自宅の庭に枯山水を作ってみたい」「小さな坪庭でも本格的な枯山水はできるの？」と考えている方も多いのではないでしょうか。枯山水というと、京都のお寺にある格式高い庭園をイメージしがちですが、実は一般住宅の坪庭や玄関脇などの小さなスペースでも、DIYで作ることができます。石と砂だけで構成されるシンプルな庭だからこそ、ポイントを押さえれば初心者でも挑戦しやすいのが魅力です。この記事では、枯山水の基本から、作る前に決めておくこと、DIYの具体的な手順、砂紋の種類と描き方、さらに室内で楽しめる庭園キットまでをわかりやすく解説します。


## 枯山水とは？自宅でも作れる日本庭園

枯山水は、日本を代表する庭園様式のひとつです。水を使わずに、石と砂だけで雄大な自然を表現する独特の美しさは、多くの人を魅了してきました。まずは、枯山水とはどのような庭なのか、代表的な龍安寺の石庭の特徴、そして自宅でも作れる理由とメリット・デメリットについて確認していきましょう。


### 枯山水とは？水を使わず石と砂で山水を表現する庭

枯山水（かれさんすい）とは、池や川などの実際の水を使わずに、石や白砂、砂利、苔、地形の高低などで山水の風景を表現する日本庭園の様式です。

枯山水の最大の特徴は、「見立て」という考え方にあります。見立てとは、あるものを別のものになぞらえて表現する手法のことです。枯山水では、それぞれの素材が次のような景色を表しています。

| 素材 | 見立てている景色 |
| --- | --- |
| 石 | 山・島・滝 |
| 白砂・砂利 | 海・川・水面・雲 |
| 砂紋（熊手で描く筋） | 水の流れ・波 |
| 苔・植物 | 森・大地 |

たとえば、白い砂利を敷き詰めれば水面に、石の周りに円を描けば島に打ち寄せる波に見立てることができます。

枯山水は、もともと禅寺の庭園として発展してきました。見る人の心を静め、思索や瞑想をするための場として親しまれてきたのです。近年では、シンプルで洗練されたデザインや手入れのしやすさから、住宅の庭や坪庭にも取り入れられるケースが増えています。


### 龍安寺の石庭に見る枯山水の特徴

枯山水の代表例として広く知られているのが、京都・龍安寺の石庭です。龍安寺は臨済宗妙心寺派の寺院で、その石庭は枯山水の美しさを体感できる場所として、国内外から多くの人が訪れています。

龍安寺の石庭は、白砂が敷き詰められた空間に15個の石が配置されたシンプルな構成です。しかし、その配置には工夫が凝らされており、どの場所に立って、どの角度から見ても、15個すべての石が一度に見えないように造られていると言われています。

また、石の配置が何を表しているのかについては、さまざまな説があります。

- 大海に浮かぶ島々を表している
- 雲の上に浮かぶ山々を表している
- 母虎が子虎を連れて川を渡る「虎の子渡し」を表している

このように、明確な正解が示されていないのも枯山水の奥深さです。その庭が何を表現しているのか、石や砂のひとつひとつが何を意味しているのかを、自分で想像しながら眺めることこそが、枯山水の楽しみ方と言えるでしょう。自宅に枯山水を作る際も、こうした見方を参考にすると、より味わい深い庭になります。


### 自宅の坪庭や小さなスペースでも枯山水は作れる

結論から言うと、枯山水は自宅の坪庭や小さなスペースでも十分に作れます。有名なお寺の庭というイメージから、ハードルが高いと感じる方もいるかもしれませんが、一般住宅の庭に枯山水を作ってはいけないというルールはありません。

坪庭とは、建物の間や中庭、玄関の脇などに造られた小規模な和風庭園のことです。限られた空間に自然を再現できるため、見る人の心を癒してくれます。枯山水は石と砂を中心に構成されるため、こうした小さなスペースとの相性が抜群です。

枯山水を作れる場所の例としては、次のようなところが挙げられます。

- 坪庭や中庭
- 玄関先やアプローチの脇
- 和室や縁側から見える庭の一角
- ベランダの一角

また、1〜2㎡ほどの狭い場所であっても、見る方向を絞り込めば、主石と脇石の重なりを調整して奥行きのある景色をつくれます。狭いからこそ、余白を活かした洗練された枯山水に仕上げられるのです。スペースが限られていても、あきらめずに挑戦してみましょう。


### 自宅に枯山水をつくるメリット・デメリット

自宅に枯山水をつくる前に、メリットとデメリットの両方を知っておくことが大切です。

まず、主なメリットは次のとおりです。

| メリット | 内容 |
| --- | --- |
| 癒しの効果がある | 砂紋や石組みを眺めるだけで心が落ち着く |
| 住宅デザインと調和する | 和モダンやシンプルな住宅、洋風の家にも合う |
| 省スペースで楽しめる | 坪庭や玄関脇など小さな場所でも作れる |
| 管理の手間が少ない | 植物が少なく、草刈りや水やりの負担が軽い |

一方で、次のようなデメリットもあります。

| デメリット | 内容 |
| --- | --- |
| 初期費用がかかる | 景石や白砂の質によっては高額になる |
| 日常的な手入れが必要 | 落ち葉の掃除や砂紋の描き直しが欠かせない |
| 多目的に使いにくい | 鑑賞用の庭のため、遊びやバーベキューには不向き |

枯山水は池のある庭や植物の多い庭に比べると、管理が楽な庭です。ただし、まったく手入れが不要というわけではありません。ライフスタイルや庭の使い方を家族で話し合ったうえで、取り入れるかどうかを判断しましょう。


## 枯山水を作る前に決めること

枯山水づくりで失敗しないためには、いきなり石や砂利を買いに行くのではなく、事前の計画が大切です。作る場所や見る位置、周辺の環境、デザイン、予算を決めておくことで、作業がスムーズに進み、完成後の満足度も高まります。ここでは、枯山水を作る前に決めておきたい4つのポイントを紹介します。


### 庭を作る場所とどこから見るかを決める

枯山水づくりは、まず作る場所を決めることから始めましょう。庭全体を使うのか、玄関先の坪庭やベランダなど限られたスペースに作るのかによって、デザインや必要な素材の量が大きく変わるからです。

場所を決めるときに、特に重要なのが「どこから見るか」という視点です。枯山水は中を歩き回って楽しむ庭ではなく、室内や縁側、玄関などの限られた場所から眺める庭です。そのため、鑑賞する位置を最初に決めておくと、石の向きや砂紋の流れが自然と決まります。

また、砂紋は上を歩くと崩れてしまうため、人の通り道になる場所は避けましょう。場所選びでは、次の点を確認してください。

- 家の中や玄関から眺めやすいか
- 子どもやペットが歩き回らない場所か
- 宅配や来客の通り道になっていないか
- 植物を置く場合は日当たりや風通しがよいか

上を歩くものがなく、落ち着いて眺められる場所が枯山水には適しています。


### 排水・日当たり・落葉など環境条件をチェックする

枯山水を美しく保つためには、作る前に周辺の環境条件を確認しておくことが欠かせません。日当たりや風通し、排水の状態によって、苔や植物の育ち方や、砂利の状態が大きく変わるからです。

着工前には、次のポイントをチェックしておきましょう。

| チェック項目 | 確認するポイントと対策 |
| --- | --- |
| 排水 | 雨の後に水たまりが残る場所は、勾配や砕石層、排水溝を検討する |
| 日当たり | 苔は直射日光や乾燥に弱いため、半日陰が適している |
| 落葉 | 大きな落葉樹の真下は、秋の掃除の回数が増える |
| 搬入経路 | 一人で持てない大きな景石を安全に運べるか確認する |

特に注意したいのが排水です。雨が多い地域や水はけの悪い場所では、排水対策をしないと砂利が流れたり偏ったりして、せっかくの砂紋が崩れてしまいます。また、苔が傷む原因にもなります。

環境条件に問題がある場合は、無理にその場所に作るのではなく、場所を変える、排水工事を行うなどの計画を立てましょう。


### 和風・和モダンなど庭のデザインを決める

場所が決まったら、どのような雰囲気の枯山水にしたいのか、デザインを具体的にイメージしておきましょう。テーマを決めておくことで、石や砂利、苔、植栽の選び方に統一感が生まれ、完成後の満足度も高まります。

枯山水のデザインは、大きく分けて次の2つのスタイルがあります。

| スタイル | 特徴 | 合う住宅 |
| --- | --- | --- |
| 伝統的な和風 | 苔や樹木を取り入れた落ち着いた雰囲気 | 和風住宅・和室のある家 |
| 和モダン | 白やグレーを基調にした直線的でシンプルな雰囲気 | モダン住宅・洋風住宅 |

モノトーンを基調にした無駄のない枯山水は、和風建築だけでなく、意外にも洋風の建築やシンプルな外観の住宅ともよく合います。

デザインを考える際は、お寺の庭園の写真や雑誌、専門書などを参考にするのがおすすめです。実在する枯山水を見ることで、石の配置や砂紋の描き方のイメージがつかみやすくなります。気に入ったデザインを参考に、自分なりのイメージを膨らませてみましょう。


### 予算と優先順位を確認する

枯山水を作る前に、予算と優先順位を確認しておくことも大切です。枯山水は、石や砂利の種類と量、苔や植栽の有無、DIYで作るかプロに依頼するかによって、費用に大きな差が出るからです。

費用を左右する主な要素は、次のとおりです。

- 景石の大きさや種類
- 砂利の種類と敷く面積
- 苔や植栽を取り入れるかどうか
- 灯籠やつくばいなど和のオブジェクトを置くかどうか
- DIYかプロへの依頼か

予算に限りがある場合は、すべてを一度にそろえようとせず、優先順位を決めて段階的に作る方法がおすすめです。たとえば、まずは石組みと砂紋だけでシンプルな枯山水を作り、余裕ができたら苔や植栽、和のオブジェクトを追加していくという進め方もできます。

また、大きな石や木を扱う場合や、作業が難しいと感じる部分だけをプロに依頼するという選択肢もあります。無理のない範囲で、自分に合った方法を選びましょう。


## 枯山水の作り方｜DIYの手順

ここからは、自宅で枯山水をDIYで作る具体的な手順を紹介します。基本的な流れは、設計図を描く、整地する、防草シートを敷く、石や植物を配置する、砂利を敷く、砂紋を描くの6ステップです。ひとつひとつの工程を丁寧に進めることが、美しい枯山水を長く楽しむためのポイントです。


### ①設計図・レイアウトを描く

最初のステップは、設計図やレイアウトを描くことです。いきなり作業を始めるのではなく、まずは庭全体のイメージを紙に描き出し、石・砂・苔などの配置を決めておきましょう。

レイアウトを描く際は、家の中や玄関など、鑑賞する位置からどの角度で見えるかを意識することが大切です。見る位置を基準にすると、主石の向きや砂紋の流れが決まり、より洗練された印象に仕上がります。

レイアウトを考えるときのコツは、次のとおりです。

- 庭の主役となる主石の位置を最初に決める
- 石は等間隔に並べず、バランスを崩して配置する
- 主石の周りには砂面（余白）を残す
- 砂紋の流れる方向を矢印で書き込んでおく

特に意識したいのが余白です。狭い場所ほど、石やオブジェクトを足したくなりますが、主石の周囲に砂面を残したほうが視線が止まり、庭が広く見えます。何も置かない「間」も、枯山水のデザインの一部なのです。実在する枯山水の写真を参考にしながら、自分だけのレイアウトを考えてみましょう。


### ②整地をして地面を固める

レイアウトが決まったら、枯山水を作る場所を整地します。整地は、完成後の美しさを左右する最も重要な工程のひとつです。地面が平らで固まっていないと、砂利が沈んだり偏ったりして、砂紋がすぐに崩れてしまうからです。

整地は、次の手順で行います。

1. 草や石、木の根をスコップで取り除く
2. レーキや板で地面の凹凸をならす
3. 雨水が抜ける方向にわずかな勾配をつける
4. ハンドタンパーなどで地面を押し固める

ポイントは、完全な水平にしないことです。わずかに勾配をつけておくことで、雨水がたまらず排水されやすくなります。

地面を固める作業は、靴跡が深く残らない状態になるまで、端や隅もしっかり行いましょう。1〜2㎡程度の狭い範囲であれば、ハンドタンパーがなくても、足や板で踏み固めて代用できます。

なお、除草剤を使う場合は、作業の1〜2週間前にまいておくと効果的です。


### ③防草シートを敷く

整地が終わったら、雑草対策として防草シートを敷きます。雑草が生えると見た目が悪くなるだけでなく、砂紋も崩れてしまうため、防草シートは枯山水づくりに欠かせません。省略すると、数ヶ月で雑草が生えてくることもあります。

防草シートは、水がたまらない透水性のタイプを選びましょう。雨水が下へ抜けるため、砂利が流れたり水たまりができたりするのを防げます。

防草シートを敷くときのポイントは、次のとおりです。

| 作業 | ポイント |
| --- | --- |
| シートを敷く | 隙間ができないよう、継ぎ目を10〜15cmほど重ねる |
| Uピンで固定する | 平地は50cm〜1m間隔、重ね部分は50cm間隔で打つ |
| テープで補強する | 重なり部分、塀との接触部分、Uピンの上に貼る |

雑草は生命力が非常に強く、わずかな隙間からでも生えてきます。シートの重なり部分や、塀や壁のコンクリートと接する部分は、専用のテープでしっかり補強しておきましょう。丁寧に敷いておくことで、完成後の管理がぐっと楽になります。


### ④石や植物を配置する

防草シートを敷いたら、設計図に沿って石や植物を配置していきます。石は枯山水の骨格ともいえる要素で、配置によって庭の印象が大きく変わります。

石組みの基本は、主石から決めることです。まずは庭の主役となる主石を選び、その石の最も落ち着いて見える面を鑑賞する位置に向けて据えます。そのあとで、副石や補助石を添えていきます。

代表的な石組みに、中央の主石と左右の脇石で構成する「三尊石組」があります。配置のコツは次のとおりです。

- 3つの石で不等辺三角形をつくる
- 石を等間隔に並べない
- 高さ・傾き・前後の位置に変化をつける
- 主石・副石・補助石の大きさに3:2:1ほどの差をつける

石の位置は、2〜3方向から確認しながら仮置きし、決まったら締まった土や砕石に根入れしてぐらつかないよう固定しましょう。

スペースに余裕があれば、苔や低木などの植物を加えると奥行きが生まれます。石に苔をつけると、より山らしい雰囲気になります。なお、大きな石は二人以上で安全に動かしてください。


### ⑤砂利を敷く

石や植物の配置が終わったら、砂利を敷きます。砂利は枯山水で水面や川の流れを表す重要な要素です。

砂利は、白っぽいものを選ぶと庭全体が明るく広く見えます。庭の雰囲気に合わせて、次のように選ぶのがおすすめです。

| 砂利の種類 | 特徴 | 合う雰囲気 |
| --- | --- | --- |
| 白川砂利 | 白に茶色が混ざった色合い | 伝統的な和風 |
| 白川みかげ砂利 | 白にグレーが混ざった色合い | 和モダン・和風の両方 |

砂利の大きさは「分（ぶ）」という単位で表され、1分は約3mmが目安です。砂紋を描くなら、京都の寺院でも多く使われている3分（約10mm）サイズが適しています。

敷く厚さは、防草シートが見えないよう3〜5cm（目安は約4cm）にしましょう。必要な量は1㎡あたり20kg袋で3〜4袋程度が目安です。ただし、粒の大きさによって必要量は変わるため、最初に全量を開けず、一袋ずつ均しながら不足を確認すると無駄がありません。


### ⑥砂紋を描く

砂利を敷き終えたら、仕上げに砂紋を描きます。砂紋は水の流れや波を表現する模様で、描くことで一気に枯山水らしい雰囲気に仕上がります。

砂紋を描くときは、枯山水専用のレーキを使うと均一なラインが描けます。専用のレーキがない場合は、熊手や水切りワイパーなどでも代用可能です。

砂紋を描く際の大切なポイントは、次のとおりです。

- 描き始める前に砂利の表面を平らにならす
- 庭の奥から描き始め、出口付近を最後に仕上げる
- 描いた線を踏まないよう、慎重に作業する

特に重要なのが、描く順番です。庭の奥から描き始めて、最後に出口付近を仕上げるようにすれば、完成した砂紋を踏まずに外へ出られます。手前から描いてしまうと、奥へ移動するときに描いた線を踏んでしまい、描き直しになってしまいます。

せっかく描いた砂紋は大切に保ちたいものです。完成後は、描いた場所を踏んだり歩いたりしないよう、家族にも伝えておきましょう。砂紋の種類や描き方のコツは、次の章で詳しく紹介します。


## 砂紋の種類と描き方

砂紋は、枯山水の印象を大きく左右する要素です。同じ石の配置でも、描く砂紋によって穏やかな水面にも、激しい波にも見せることができます。ここでは、砂紋の種類と模様の意味、初心者でも描きやすい方法、そして直線・曲線・渦をきれいに描くコツを紹介します。


### 砂紋の種類と模様の意味

砂紋（さもん）とは、白砂や砂利の表面に熊手やレーキで描く筋模様のことです。なお、自然に広がる水の輪を表す「波紋（はもん）」とは別の言葉なので注意しましょう。

砂紋にはさまざまな種類があり、それぞれ表現する景色が異なります。代表的な砂紋は次のとおりです。

| 砂紋の種類 | 読み方 | 表現する景色 | 描き方 |
| --- | --- | --- | --- |
| 漣紋 | さざなみもん | 穏やかな水面・一定の流れ | 庭の奥から一定間隔で直線を引く |
| 流水紋 | りゅうすいもん | 川・緩やかな流れ | 主石を避けて一方向へ曲線を流す |
| 渦巻紋 | うずまきもん | 石から広がる波・渦 | 石の近くから同心円を広げる |
| 青海波紋 | せいがいはもん | 重なる波・広い水面 | 同じ半径の円弧を連続させる |

ほかにも、荒々しい波を表現する「立浪紋」などがあります。

砂紋の模様に唯一の正解はありません。大切なのは、石の配置や庭全体のテーマに合わせて模様を選ぶことです。たとえば、静かで落ち着いた庭にしたいなら漣紋、石を島に見立てるなら渦巻紋というように、表現したい景色をイメージしながら選んでみましょう。


### 初心者でも描きやすい砂紋の描き方

初めて砂紋を描くなら、まずは平行線（漣紋）から始めるのがおすすめです。直線を一定の間隔で引くだけなので描きやすく、それだけでも静かな水の流れを表現できます。

初心者が砂紋を描くときの手順は、次のとおりです。

1. 砂利の表面をレーキの背で平らにならす
2. 庭の奥側から、出口に向かって描き進める
3. 最初の一本を基準にして、同じ間隔で直線を引いていく
4. 石の周りは最後に円を描いて仕上げる

いきなり庭で本番に挑戦するのが不安な場合は、まず試し砂で練習するとよいでしょう。浅い箱やトレーに砂を入れ、平行線・曲線・渦の3つを試してみてください。練習しておくことで、線が折れたり間隔がずれたりするクセを本番前に直せます。

また、砂紋は一度で完璧に描く必要はありません。うまくいかなかった部分は、表面を平らにならして何度でも描き直せます。気軽に挑戦できるのも、砂紋の魅力のひとつです。


### 直線・曲線・渦の描き方のコツ

砂紋を美しく描く基本は、砂面を先に平らにすること、左右に同じ圧力をかけること、そして腕だけでなく脚と腰も使うことです。そのうえで、線の種類ごとのコツを押さえましょう。

| 線の種類 | 描き方のコツ |
| --- | --- |
| 直線 | 抜きたい先を見て両手で柄を固定し、一定の歩調と速度で一気に引き切る |
| 曲線 | 柄の根元を支点に腰ごと回り、大きな弧から描いて内側を等間隔に寄せる |
| 渦 | 石の奥側から円弧を外へ広げ、最後の線を直線や曲線へつなげる |

直線は、途中で止まると線が乱れやすくなります。一区画を一気に引き切ることを意識しましょう。小さな円を描くときは、歩幅を狭めながら丁寧に描くのがポイントです。

また、使う砂利によってもレーキの当て方を変えます。細かい白砂では歯を浅く当て、粗い砂利では表面をなでる程度に当てると、粒を掘り返さずきれいに描けます。

砂紋は雨や風、落ち葉で崩れることがあります。崩れた部分だけを継ぎ足すと線が不自然になるため、周囲を平らにならしてから一区画ごと描き直しましょう。


## 庭園キットで作る枯山水

「庭がないけれど枯山水を楽しみたい」「まずは手軽に試してみたい」という方には、庭園キットを使ったミニ枯山水がおすすめです。整地や防草シートの施工、重い石の運搬が必要ないため、室内やベランダで気軽に始められます。ここでは、枯山水キットの選び方と作り方、インテリアとして楽しむ飾り方のコツを紹介します。


### 枯山水キットの選び方

枯山水キットとは、トレーや木箱などの器に、白砂、小石（景石）、小さな熊手などがセットになった商品です。庭がなくても、デスクや玄関、リビングなどで手軽にミニ枯山水を楽しめます。

枯山水キットを選ぶときは、次のポイントを確認しましょう。

| 選び方のポイント | 確認する内容 |
| --- | --- |
| サイズ | 机に置ける卓上サイズか、床に置く大きめのサイズか |
| 器の素材 | 木製・陶器・樹脂など、部屋の雰囲気に合うか |
| 砂の色と粒 | 白・グレーなどの色、粒の細かさ |
| 付属品 | 景石の数、苔、ミニ灯籠などが付いているか |
| 器の深さ | 砂がこぼれにくい深さがあるか |

置く場所の雰囲気に合わせて選ぶことも大切です。和室には木製の器、モダンな部屋にはシンプルな黒や白の器を選ぶと、インテリアになじみやすくなります。

初めての方は、必要な道具がひと通りそろったセットを選ぶと、届いたその日から枯山水づくりを楽しめます。


### 枯山水キットを使ったミニ枯山水の作り方

枯山水キットを使えば、短い時間で本格的なミニ枯山水を作ることができます。基本的な作り方は、次のとおりです。

1. 器に砂を入れ、表面を平らにならす
2. 主石となる一番大きな石の位置を決めて置く
3. 副石を、主石と不等辺三角形になるように添える
4. 苔やミニ灯籠などの付属品を配置する
5. 小さな熊手で、奥から手前に向かって砂紋を描く

ミニ枯山水でも、屋外の枯山水と同じく主石から配置するのが基本です。石を器いっぱいに並べるのではなく、余白を残すと、小さな器の中でも広がりのある景色になります。

砂紋は、まずは平行線（漣紋）から描いてみましょう。慣れてきたら、石の周りに渦巻紋を描くと、石が島のように見えて一気に枯山水らしくなります。

キットに熊手が付いていない場合は、割り箸や竹串を束ねた自作のレーキでも砂紋を描けます。身近なもので代用できるのも、ミニ枯山水の手軽さです。


### ミニ枯山水をインテリアとして楽しむ飾り方のコツ

完成したミニ枯山水は、インテリアとして飾ることで、日々の暮らしに癒しの時間をもたらしてくれます。

置き場所としておすすめなのは、次のような場所です。

- 玄関の靴箱の上（来客の目にも留まりやすい）
- 仕事や勉強をするデスクの上（気分転換になる）
- リビングの棚やテレビボードの上
- 和室の床の間

目に入りやすく、落ち着いて眺められる場所に置くのがポイントです。

ミニ枯山水の魅力は、気分や季節に合わせて表情を変えられることです。砂紋を描き直したり、石の配置を変えたりするだけで、毎日違う景色を楽しめます。砂紋を描く時間そのものが、心を落ち着けるひとときにもなるでしょう。

きれいな状態を保つためには、次のような管理も意識しましょう。

- 使わないときはカバーをかけてホコリを防ぐ
- 器の下に敷物を敷き、砂がこぼれても掃除しやすくする
- 直射日光の当たる場所は避け、苔の色あせを防ぐ

手軽に始められるミニ枯山水で、自宅に和の癒し空間を取り入れてみてはいかがでしょうか。
