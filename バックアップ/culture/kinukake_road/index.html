金閣寺・龍安寺・仁和寺を巡る「きぬかけの路」ガイド｜京都駅からのアクセス、所要時間、ランチやお土産

きぬかけの路とは？3つの世界遺産をつなぐ道

金閣寺・龍安寺・仁和寺は、京都市の北西部、衣笠山のふもとに並んでいます。まずは3つの寺の位置関係と、それらを結ぶ道について知っておきましょう。

金閣寺・龍安寺・仁和寺の位置関係

3つの寺は、北東から南西に向かって、金閣寺、龍安寺、仁和寺の順に並んでいます。これらを結ぶ全長約2.5kmの道が「きぬかけの路」です。歩道が整備されていて、ゆるやかな坂道を歩きながら寺から寺へ移動できます。

区間徒歩の目安市バスの目安
金閣寺 → 龍安寺約20〜25分59系統で約5分
龍安寺 → 仁和寺約10〜15分59系統で約3分
金閣寺 → 仁和寺約35〜40分59系統で約10分

なお、「かいがけの道」「きぬがけの道」と検索されることもありますが、正しくは「きぬかけの路（みち）」です。

名前の由来は宇多天皇の伝説

きぬかけの路の名前は、道沿いにある衣笠山（きぬがさやま）に由来します。仁和寺を開いた宇多天皇が、真夏に雪景色を見たいと望み、山に白い絹を掛けさせたという伝説から、衣笠山は「きぬかけ山」とも呼ばれてきました。道の名前にも、この優雅な逸話が受け継がれています。

3か所とも「古都京都の文化財」の世界遺産

金閣寺・龍安寺・仁和寺は、1994年にそろって世界遺産「古都京都の文化財」の構成資産に登録されました。これほど近い距離に世界遺産が3つ並ぶ場所は京都でも珍しく、1日で効率よく巡れるのがこのエリアの大きな魅力です。

寺院宗派創建こんな人におすすめ
金閣寺（鹿苑寺）臨済宗相国寺派1397年ごろ（義満の北山殿）京都らしい華やかな景色を見たい
龍安寺臨済宗妙心寺派1450年石庭を前に静かに過ごしたい
仁和寺真言宗御室派888年御所の雅な建物と庭を味わいたい

京都駅から金閣寺へのアクセス

金閣寺は京都駅から離れた市の北西部にあり、駅から直接歩いて行ける距離ではありません。ここでは最寄りのバス停と駅、京都駅からの行き方を紹介します。

金閣寺の最寄りのバス停と駅

金閣寺にもっとも近いのは市バスのバス停です。鉄道の駅は少し離れているため、電車を使う場合もバスとの組み合わせが基本になります。

最寄り金閣寺までの目安
市バス「金閣寺道」徒歩約5分（101・102・204・205系統など）
市バス「金閣寺前」徒歩約3分（12・59系統）
地下鉄烏丸線「北大路駅」市バスに乗り換えて約10分
嵐電「等持院・立命館大学衣笠キャンパス駅」徒歩約20分

金閣寺の住所は「京都市北区金閣寺町1」です。地図アプリで検索するときは「金閣寺町」や正式名称の「鹿苑寺」でも見つかります。ちなみに「金額寺」と入力しても目的の寺は出てこないことがあるので、漢字には注意しましょう。

京都駅から市バスで行く方法

乗り換えなしで行けるのは、京都駅前のバスターミナルから出る市バスです。

  • 205系統（B3のりば）：「金閣寺道」まで約40分
  • 101系統（B2のりば）：二条城や北野天満宮を経由して「金閣寺道」まで約40分

運賃は大人230円の均一料金で、ICカードも使えます。ただし観光シーズンは道路が渋滞し、バスも満員になりやすいため、時間に余裕を持って出発しましょう。荷物が多い場合や、3〜4人で移動する場合はタクシーも便利で、京都駅から約30分が目安です。

電車を使って金閣寺へ行く方法

渋滞を避けたいなら、地下鉄とバスを組み合わせる方法がおすすめです。

  1. 京都駅から地下鉄烏丸線（国際会館方面）に乗る
  2. 「北大路駅」で下車（約15分）
  3. 北大路バスターミナルから市バス101・102・204・205系統に乗る
  4. 「金閣寺道」で下車（約10分）

地下鉄の区間は渋滞の影響を受けないため、所要時間が読みやすいのがメリットです。また、嵐電北野線を使う場合は「等持院・立命館大学衣笠キャンパス駅」や「龍安寺駅」から歩くこともできます。龍安寺から先に回り、きぬかけの路を歩いて金閣寺へ向かうルートも楽しめます。

「金閣寺道」バス停から金閣寺まで

「金閣寺道」バス停で降りたら、西大路通から北へ入る参道を進みます。案内表示が多く、人の流れについていけば迷うことはほとんどありません。徒歩約5分で総門に着き、その先の受付で拝観券を受け取ります。帰りは同じ道を戻るか、きぬかけの路を西へ進んで龍安寺へ向かいましょう。

金閣寺（鹿苑寺）の特徴と見どころ

金閣寺の正式名称は「鹿苑寺（ろくおんじ）」です。金閣（舎利殿）が有名なため、寺全体が金閣寺と呼ばれるようになりました。ここでは金閣寺の特徴と、境内で見ておきたい場所を紹介します。

金閣寺の特徴と大きさ

金閣寺は、室町幕府3代将軍の足利義満が建てた山荘「北山殿」がもとになっています。金閣（舎利殿）は三層の楼閣で、一層は寝殿造、二層は武家造、三層は禅宗様と、層ごとに異なる建築様式を組み合わせているのが特徴です。二層と三層には金箔が貼られ、屋根の上では金色の鳳凰が輝いています。

金閣の高さは約12.5メートルで、写真で見るよりも小ぶりに感じる方もいるかもしれません。現在の建物は、1950年の焼失後、1955年に再建されたもので、1987年には漆の塗り替えと金箔の貼り替えが行われました。

境内には何がある？鹿苑寺の見どころ

金閣寺の境内は、一方通行の順路に沿って回るようになっています。金閣以外にも、次のような見どころがあります。

見どころ特徴
金閣（舎利殿）三層の楼閣。鏡湖池越しに眺める
鏡湖池金閣を映す池。葦原島や九山八海石が浮かぶ
陸舟の松義満が手植えしたと伝わる舟の形の松
銀河泉・龍門の滝義満がお茶の水に使ったと伝わる泉と、鯉魚石の滝
安民沢と白蛇の塚池の中の小島に白蛇の塚が立つ
夕佳亭江戸時代の茶人・金森宗和ゆかりの茶室
不動堂石不動明王を祀る境内最古の建物

寺院の庭（寺庭）を歩くときは、建物だけでなく、池や石、松の配置にも目を向けてみましょう。それぞれの見どころのくわしい解説は、金閣寺の見どころ10選の記事で紹介しています。

逆さ金閣をきれいに見るコツ

鏡湖池の水面に金閣が映り込む「逆さ金閣」は、金閣寺を代表する景色です。水面が鏡のように見えるのは、風がなく晴れた日です。次のポイントを押さえると、きれいな逆さ金閣に出会いやすくなります。

  • 風が弱い朝の時間帯を狙う
  • 順路の最初にある池の南側から眺める
  • 空が青く澄んだ日を選ぶ
  • 冬は雪化粧した「雪の金閣」と逆さ金閣の両方を楽しめることもある

撮影スポットとなる池のほとりは混み合うため、写真を撮ったら後ろの人に場所を譲りながら、少し位置をずらして眺めてみましょう。

金閣寺のご利益とお守り

金閣寺では、拝観券として「金閣舎利殿御守護」と書かれたお札を受け取ります。開運招福や家内安全を願うお札とされ、持ち帰って自宅に飾る人も多くいます。

順路の終盤にある不動堂には、弘法大師の作と伝わる石不動明王が祀られ、厄除けや開運のご利益があるとして信仰を集めてきました。授与所では金色のお守りも人気で、金運や開運を願うお土産としても選ばれています。

修学旅行で金閣寺を見るときのポイント

金閣寺は修学旅行の定番スポットです。見学時間が限られているときは、次のポイントを意識すると学びが深まります。

  • 金閣の三層の建築様式の違いを見比べる
  • 義満が北山殿を築いた室町時代の「北山文化」を調べておく
  • 銀閣寺（慈照寺）との違いを比べてみる
  • 1950年の焼失と再建の歴史を知っておく

春や秋は修学旅行生も多く、午前中は特に混雑します。班行動の場合は、順路の出口付近で集合場所を決めておくと安心です。

龍安寺と仁和寺の見どころ

金閣寺から足をのばして、きぬかけの路沿いの龍安寺と仁和寺も訪れてみましょう。華やかな金閣寺とは異なる、静かで奥深い魅力があります。

龍安寺｜世界遺産の石庭と鏡容池

龍安寺は、1450年に細川勝元が創建した臨済宗妙心寺派の寺院で、1994年に世界遺産に登録されました。白砂と15個の石だけで構成された方丈庭園（石庭）は、枯山水の代表作として世界的に知られています。どこから見ても15個すべての石が見えないとされる配置や、作者がわかっていない謎も魅力です。

境内には大きな鏡容池や、「吾唯足知（われただたるをしる）」の言葉で知られる知足のつくばいもあります。くわしくは龍安寺の見どころや龍安寺の石庭の記事をご覧ください。

仁和寺とは？「御室御所」と呼ばれる門跡寺院

仁和寺は、888年に宇多天皇が完成させた真言宗御室派の総本山です。宇多天皇が出家後に住まいとしたことから、皇族が住職を務める門跡寺院の筆頭となり、「御室御所（おむろごしょ）」と呼ばれてきました。周辺の「京都御室」という地名も、この御室に由来しています。

仁和寺も1994年に世界遺産に登録されています。主な見どころは次のとおりです。

  • 高さ約18メートルの二王門
  • 御所の紫宸殿を移築した国宝の金堂
  • 江戸時代に建てられた五重塔
  • 宸殿と北庭・南庭からなる御殿と御所庭園
  • 背丈の低い遅咲きの桜として知られる御室桜

庭園の見どころは、仁和寺の庭園の見どころの記事でくわしく紹介しています。

足をのばして嵐山の天龍寺へ

時間に余裕があれば、嵐電を使って嵐山へ向かうのもおすすめです。龍安寺駅や御室仁和寺駅から嵐電北野線に乗り、帷子ノ辻駅で嵐山本線に乗り換えると、嵐山駅まで約20分で着きます。

嵐山の天龍寺も世界遺産で、夢窓疎石が作庭した曹源池庭園が見どころです。庫裏に入ると、天龍寺の管長を務めた平田精耕老師が描いた大きな達磨図が出迎えてくれます。「天龍寺のだるま」として親しまれ、写真で見たことがある方も多いでしょう。

所要時間とモデルコース

3つの寺を効率よく回るために、それぞれの所要時間の目安と、おすすめのコースを紹介します。

金閣寺・龍安寺・仁和寺の所要時間

寺院拝観の所要時間ポイント
金閣寺約30〜40分一方通行の順路で回る
龍安寺約45分〜1時間石庭の前で座る時間を見込む
仁和寺約1時間〜1時間30分御殿と境内の両方を見る場合

金閣寺は順路が決まっているため、混雑していても所要時間はあまり変わりません。仁和寺は境内が広く、御殿の拝観に加えて金堂や五重塔まで歩くと1時間以上かかります。移動時間を含めると、3か所で4〜5時間ほどを見ておくと安心です。

半日で3つの世界遺産を巡るモデルコース

混雑を避けるなら、開門直後の金閣寺からスタートするのがおすすめです。

  1. 9:00　金閣寺を拝観（約40分）
  2. 9:45　きぬかけの路を歩いて龍安寺へ（約20分）
  3. 10:10　龍安寺の石庭と鏡容池を見学（約1時間）
  4. 11:15　きぬかけの路を歩いて仁和寺へ（約15分）
  5. 11:30　仁和寺の御殿と境内を拝観（約1時間30分）
  6. 13:00　御室仁和寺駅周辺でランチ、または嵐電で嵐山へ

歩くのが不安な方は、各寺のあいだを市バス59系統で移動すると体力を温存できます。逆に嵐山方面から来る場合は、嵐電で御室仁和寺駅まで行き、仁和寺→龍安寺→金閣寺の順に回るとスムーズです。

金閣寺から八坂神社・嵐山へ移動する方法

金閣寺のあとに東山方面へ向かう方も多いでしょう。金閣寺から八坂神社へは、「金閣寺道」から市バス205系統などで「四条河原町」まで約40分、そこから四条通を東へ歩いて約10分です。観光シーズンは渋滞で時間がかかりやすいため、タクシー（約30分）を使うのも一つの方法です。

嵐山へ向かう場合は、先に紹介した嵐電を使うルートのほか、金閣寺前から市バスで移動することもできます。行き先に合わせて、帰りのルートも事前に確認しておきましょう。

周辺のランチ・カフェとお土産

寺巡りの合間の食事や休憩、お土産選びも旅の楽しみです。エリアごとの特徴を紹介します。

金閣寺周辺で安くランチをするなら

金閣寺の周辺で手軽に食事をするなら、「金閣寺道」バス停のある西大路通沿いがおすすめです。うどんやそばの店、定食屋、ファストフード店などがあり、1,000円前後で食事ができる店も見つかります。参道沿いには、軽食や甘味を出す茶店もあります。

少し特別なランチにしたいなら、龍安寺の塔頭・西源院の湯豆腐や、仁和寺の門前にある飲食店も候補になります。昼どきはどこも混み合うため、11時台の早めの時間か、13時以降にずらすとゆっくり過ごせます。

金閣寺周辺のカフェでひと休み

金閣寺の境内では、順路の終盤にある茶所で抹茶とお菓子をいただけます。夕佳亭の近くで庭を眺めながらひと息つけるので、歩き疲れたときの休憩にぴったりです。

境外では、西大路通沿いや、きぬかけの路から少し入った住宅地に、落ち着いた雰囲気のカフェが点在しています。寺巡りのあいだに温かい飲み物で体を休めると、次の寺もゆっくり楽しめます。営業日や時間は店によって異なるため、訪れる前に確認しておきましょう。

龍安寺のお土産と各寺の授与品

龍安寺のお土産では、知足のつくばいの「吾唯足知」をモチーフにした品や、石庭をデザインした手ぬぐい、絵はがきなどが人気です。「足るを知る」という言葉は、自分用のお土産としても心に残ります。授与所では、お守りや御朱印も受けられます。

寺院おすすめのお土産・授与品
金閣寺拝観券のお札、金色のお守り、金箔を使った菓子や雑貨
龍安寺「吾唯足知」の品、石庭の手ぬぐいや絵はがき、御朱印
仁和寺御室桜にちなんだ品、お守り、御朱印

販売される品は時期によって変わることがあります。石庭の静けさを家でも感じたい方は、手のひらサイズの枯山水を作ってみるのもおすすめです。枯山水の作り方の記事も参考にしてください。
