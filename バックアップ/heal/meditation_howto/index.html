瞑想とは？初心者でもできる瞑想のやり方と期待できる効果、続けるコツ

更新日：2026.11.05

「瞑想に興味はあるけれど、何をすればいいのかわからない」「じっと座っていると、かえって考えごとが止まらない」。そんなふうに感じている方も多いのではないでしょうか。瞑想は、特別な道具や場所がなくても、数分あれば始められる心のセルフケアです。この記事では、瞑想とは何か、初心者でもできる基本のやり方と、期待できる効果、続けるコツを紹介します。

瞑想とは？

「今この瞬間」に意識を向ける練習

瞑想とは、呼吸や体の感覚など、ひとつのことに意識を向け、心を静めていく練習のことです。過去の後悔や未来の不安から離れて、「今この瞬間」に気づく時間をつくることが目的です。何も考えない状態を目指すのではなく、浮かんでくる考えに気づき、そっと意識を戻すことをくり返します。

瞑想のおもな種類

種類特徴
呼吸の瞑想（マインドフルネス瞑想）呼吸の感覚に意識を向ける、もっとも基本的な瞑想
坐禅禅寺で行われてきた、姿勢と呼吸を整えて座る修行
歩く瞑想足の裏の感覚や一歩一歩の動きに意識を向けて歩く
ボディスキャン体の各部分に順番に意識を向けて、感覚を味わう

初心者でもできる瞑想のやり方

基本の呼吸の瞑想

  1. 椅子に浅めに座るか、床にあぐらをかいて座る
  2. 背筋を自然にのばし、肩の力を抜いて、手はひざの上に置く
  3. 目を軽く閉じるか、斜め下をぼんやり見る
  4. 鼻からゆっくり呼吸し、空気が出入りする感覚に意識を向ける
  5. 考えごとが浮かんだら、「考えていたな」と気づき、呼吸に意識を戻す
  6. 最初は3〜5分を目安に行い、ゆっくり目を開けて終える

雑念が浮かんでも大丈夫

瞑想中に考えごとが浮かぶのは自然なことです。うまくできていないと自分を責めず、気づいたら呼吸に戻る、そのくり返し自体が瞑想の練習です。気が散った回数が多いほど、意識を戻す練習をたくさんできたと考えましょう。

瞑想に期待できる効果

心と体への効果

  • 呼吸がゆっくりになり、リラックスしやすくなる
  • 目の前のことに集中しやすくなる
  • イライラや不安な気持ちに気づき、距離を置きやすくなる
  • 気持ちの切り替えがしやすくなる
  • 寝る前に行うと、心が落ち着いて眠りにつきやすくなる

効果の感じ方には個人差があります。数回で劇的な変化を期待するより、毎日の習慣として続けることを大切にしましょう。イライラしたときの対処法は、イライラが止まらないときの対処法の記事でも紹介しています。

瞑想を続けるコツ

続けるためのポイント

  • 朝起きたあとや寝る前など、時間を決めて行う
  • 1日3分など、短い時間から始める
  • 静かで落ち着ける場所を決めておく
  • タイマーを使い、時間を気にせず集中できるようにする

「動く瞑想」もおすすめ

じっと座るのが苦手な方は、手を動かしながら意識を集中させる「動く瞑想」もおすすめです。白砂に熊手で砂紋を描く枯山水は、一本一本の線に意識を向けるうちに、自然と心が静まっていきます。枯山水の作り方の記事で始め方を紹介しています。京都の禅寺の石庭を眺める時間も、瞑想に近い体験になります。龍安寺の見どころの記事もご覧ください。

まとめ

瞑想とは、呼吸や体の感覚に意識を向け、「今この瞬間」に気づく練習です。背筋をのばして座り、呼吸に意識を向け、考えごとが浮かんだら呼吸に戻る。この基本を、まずは3〜5分から始めてみましょう。

リラックスや集中、気持ちの切り替えなどの効果が期待できますが、感じ方には個人差があります。時間を決めて少しずつ続け、じっと座るのが苦手なら枯山水などの「動く瞑想」も取り入れてみてください。
